# Lesson 01: Backend Starter Project with JS and Express

## Overview
In this lesson, we set up a fresh backend starter project using JavaScript and Express.js.

## Topics Covered
- Project initialization with npm
- Express.js framework setup
- Basic routing
- Project structure best practices

## Files Created
- `package.json` - Project dependencies and scripts
- `src/` - Source code directory
- `.gitignore` - Files to ignore in version control

## How to Run
1. Install dependencies: `npm install`
2. Start the server: `npm start` or `node src/index.js`
3. Visit http://localhost:3000 in your browser

## Learning Objectives
By the end of this lesson, students should be able to:
- Create a new Node.js project from scratch
- Set up an Express server
- Define routes and handle HTTP requests
- Structure a backend project effectively
