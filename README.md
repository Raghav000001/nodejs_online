# Backend Online - Teaching Repository

This repository is used for teaching students backend development concepts.

## Structure

- `01_backend_starter_project/`: Contains the code from the first lesson where we set up a fresh backend starter project with JavaScript and Express.

## Lesson 01: Backend Starter Project with JS and Express

In the first lesson, we covered:
- Initializing a Node.js project
- Setting up Express.js
- Creating basic routes
- Environment configuration

See the README in the `01_backend_starter_project` folder for detailed steps.

## How to Use

Each numbered folder represents a lesson in the series. Students can clone this repository and explore each lesson's code.
